# 六种子 ProtT5 错题的逐样本互补对照

在 GHXTox 的 6,387 条训练集外折预测上，复用已经冻结的六种子一维难例分型，保持原标签及 0.5 中性点。两种历史 PepBERT 各复用两个种子。纯序列 ESM-2 的历史逐样本文件未在已核查目录找到，因此用已有 650M 残基嵌入做均值池化，并与均值 ProtT5、PepBERT、ESM-IF1 使用同一个标准化逻辑回归头（C=0.1）。还比较了 ProtT5+ESM-2、ESM-2+ESM-IF1 的特征拼接。拼接会增加特征维数，旧 EGNN 则使用不同架构，两者的比较仅用来筛查互补性。所有新探针只在每个外折的 train 角色拟合，calibration 角色设定操作点，外折 test 角色只用来评估。没有使用 Test1/Test2。

样本通过 ID、序列、标签、序列组和外折核对。历史 PepBERT 的 ID 用保留的桥接表对齐，逐条复核序列 SHA256。对已有预测和新探针以 0.5 作参考，同时对有折内校准预测的候选使用同样误报预算。五折校准集负类误报数分别为 17、13、13、10、16，各候选全部达到相同计数。预算只在校准集上对齐，外折误报仍可能不同。历史 PepBERT 只有外折分数，表中单列其 0.5 参考结果。

## 主要结果

| 模型和操作点 | 救回 67 条 Cys=0 强漏判 | 纠正 6 条 Cys≥7 强误报 | 较弱反向纠正（180 条） | 1,889 条低 Cys 同背景无毒误报 | 全部 6,387 条纠正 / 添错 |
|---|---:|---:|---:|---:|---:|
| 六种子 ProtT5，0.5 | 0 | 0 | 0 | 0 | 0 / 0 |
| ProtT5 均值，同误报预算 | 1 | 0 | 46 | 4 | 77 / 306 |
| ESM-2 均值，同误报预算 | 1 | 0 | 54 | 8 | 97 / 266 |
| ProtT5 + ESM-2，同误报预算 | 0 | 0 | 47 | 5 | 83 / 234 |
| PepBERT-large 历史双种子，0.5 | 1 | 0 | 50 | 0 | 95 / 329 |
| PepBERT-small 历史双种子，0.5 | 0 | 0 | 46 | 0 | 87 / 408 |
| 现有无化学位点 EGNN，同误报预算 | 0 | 0 | 46 | 2 | 92 / 214 |
| ESM-IF1 均值，同误报预算 | 0 | 0 | 50 | 18 | 105 / 455 |
| ESM-2 + ESM-IF1，同误报预算 | 2 | 1 | 51 | 17 | 107 / 298 |

同背景低 Cys 无毒组使用同折、相同 Cys 数、长度差不超过 3、不同序列组且六种子有毒概率不超过 0.10 的负类参照。六种子在该参照组的误报为 0 是由选组规则决定的。高 Cys 强误报对应的高支持同背景有毒参照仅 26 条，其统计也保留在分组表。全体纠正和添错是候选单独判断与六种子判断的差值，适合作为互补性诊断。按实际门控调用候选会产生另一组纠正和添错。

- **一维互补在较弱反向组有线索。** 同一线性头下，ESM-2 在 180 条中答对 54 条，ProtT5 答对 46 条，分别独对 24 和 16 条。五折答对数分别为 8、11、11、10、14 对 7、14、8、10、7，ESM-2 三折占优、一折持平、一折落后。按折分层重采样序列组 5,000 次，正确率差 +4.44 个百分点的探索性 95% 区间为 −2.23 至 +11.30 个百分点，条件于固定预测。ESM-2 独对样本涉及多个家族，6 条没有家族注释，已注释的单个家族标签最多 2 条。两路均值拼接只答对 47 条，因此目前支持逐条分析互补，暂不足以支持替换或直接拼接。
- **极端 Cys 组收益少。** 同误报预算下，纯 ESM-2 唯一救回的低 Cys 强漏判是 fold3 的 bombolitin 家族 `peptide_228`。加入 ESM-IF1 又救回 fold4 的 grammistin 家族 `peptide_58`。高 Cys 强误报仅拼接结构表征后有 1 条纠正，即带历史片段提示的 `peptide_3270`。这组样本量小且依赖原标签。
- **加入结构的直接对照尚不足以支持新门控。** ESM-2 加 ESM-IF1 相对纯 ESM-2，在全体样本中新纠正 111 条、添错 133 条。低 Cys 强漏判多救 1 条，但 1,889 条同背景无毒误报从 8 增至 17。较弱反向组新纠正 8 条、添错 11 条。旧 EGNN 在相同校准误报预算下单独救回 46 条较弱反向，两个极端强反向组均为零。

## 后续判断

ESM-2 可以保留为较弱反向样本的一维互补候选。若继续，用同一逐残基分类头比较冻结 ProtT5 和 ESM-2，预先固定折、阈值和对照组，再看新增纠错是否能在留出序列组复现。均值探针只能检查当前表示与轻量分类头的组合，不能判断所有 ProtT5 或结构表示的上限。低 Cys 强漏判和高 Cys 强误报仍保留为独立组，当前结果不足以启动针对它们的门控训练。
