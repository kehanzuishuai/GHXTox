# 空间与序列选边的配对初试

2026-11-08。使用 GHXTox 已有训练缓存和六种子嵌套划分的 fold0，随机种子 42。两组均为无化学位点 EGNN，同一网络尺寸、输入、优化器、训练数据和固定 3 轮。两组的配置文件逐字段核验，只有 graph_mode 不同。每个残基保留相邻序列边，另加最多 4 条非相邻的有向入边。实验组选当前坐标距离最近的候选，对照组选序列距离最近的候选。预检覆盖短肽和 padding，核验了两组每个残基边数相同、邻边保留、无自环且空间邻居确实不同。两组均保留真实坐标、距离及置信度，因此本实验只检验**如何选边**，并未隔离全部几何信息。

对每组用 639 条校准样本拟合单调 Platt，在 1,271 条训练集留出样本（1,052 序列组）上比较。六种子一维分数来自已核验的同折分型表。融合采用相同 0.72/0.28 仅作配对诊断；分类统一用校准后的 0.5 参考点。原始评估 CSV 的预测列另含历史默认阈值，本表从原始概率重新校准并计数。
