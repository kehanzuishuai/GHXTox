# 结构专家：探索清单与下一步对照

## 目标与基线

目标是探索能否在六种子一维基础上获得新结构信息；对象不限于旧三维答对的样本。全部保留六种子一维预测，旧三种子实验仅作历史参考。先用训练数据，不使用 Test1/Test2 选择模型、样本阈值或方案。既有数据已多次观察，因此新分析均为探索。

## 本轮覆盖

核验 6387 个结构缓存的 SHA、序列、标签、ID，从 Cα 坐标计算回转半径、序列间隔大于2的8Å非局部接触比例、Cys间最小Cα距离，并以训练折外的六种子预测关联。种子离散度从另一次校准流程取六种子原始概率标准差，匹配 ID、序列、标签、组和fold；不能混用不同流程的校准概率。样本组相互重叠。几何指标、阈值均是探索性代理：距离不是二硫键、单构象不是实验结构；Cys=0 不用 Cys 专属结构特征限制。

分组包括：一维预测0.3–0.7、六种子原始标准差≥0.15、非局部联系密度≥0.15、密度高且平均pLDDT≥0.7、Cys=0、Cys≥7；事后标签仅描述一维错误及两路错误，不能作为推理时筛选条件。阈值是用于检查覆盖情况的事后设定，不能声称预测标准。训练专家不只选这些样本，应使用全部训练组；是否给予困难样本额外权重需严格外层训练内生成难度并有同预算对照。

## 后续训练对照（尚未运行）

1. 用完全相同结构缓存与固定预训练 ESM-IF1 提取表征，输入 N/CA/C；仅技术烟测成功不代表适合短肽或毒性预测。记录预训练数据及可能重叠；结构由序列预测，不是实验真值。
2. 对每个外折分别使用已有 nested_folds 的 train / validation / calibration / test 角色；仅训练部分拟合标准化和分类头，validation 选模型，calibration 单独校准，test 做留出预测。固定完整训练集，先比较同架构的结构专家与恰当无几何对照；不能以零坐标这种明显分布外输入冒充从头训练消融。表征不包含毒性标签，若预训练继续适配，绝不能使用外层test序列或结构。
3. 一维六种子固定，单独报告预训练专家与现有三维、固定 0.72/0.28 六一维＋旧三维，以及六一维＋新专家；仅在对应训练内校准/选比例，保证不同方法同等处理。严格检查旧与新预测的谱系及fold角色，不能用所有样本OOF难例标签去训练相应外折模型；仅限探索性评估，分组/相似性和重复暴露限制如实报告。
4. 再决定是否实施结构预训练继续适配、仅训练困难加权专家和受限融合；对照普通微调、等步数普通采样、序列容量/集成数量，以及预训练 vs 随机初始化和结构可控破坏；不得只看有利样本组。外折分组抽样区间不包含重训/选模不确定性。
