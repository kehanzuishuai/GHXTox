# Cys=0 共同漏判归因整合

本轮复用六种子一维留出预测、67 条原文核查、已有同实验对照及旧 UniProt 家族注释。新增每条样本所在外折 role=train 的家族注释覆盖检查。原标签来自广义毒性训练集，样本本身的标签能否溯源仍待逐条核验。

## 已经做过的工作

- 67 条强反向样本已逐条检查，62 条在已比较的多个模型里共同判为无毒。原记录按证据分为片段 22、前体 4、类似物 1、直接宿主损伤 10、特定功能效应 15、身份线索 6、条件受限结果 1、身份未确认 8。各类是用于组织核查的互斥分类。
- 已有 23 条 Mastoparan 人红细胞固定剂量排序、Ponericin 细胞毒性和溶血排序、Grammistin 同实验对照，详细读数与各模型分数见 [已有同实验分析](../cys0_common_error_assay_20261108/SAME_ASSAY_COMPARISONS.md)。
- 旧同家族匹配采用历史三种子或另一单种子条件融合，并有不同筛选条件，不是本次六种子覆盖统计。[旧分析](../cys_extreme_within_family_20261028/REPORT.md)
- Cys=0 正类强反向、片段标记及五折差异此前已有分析。去掉旧片段标记后仍存在差异，但新查出的前体、类似物等不能视为已清洗数据。[原核查](../cys0_common_error_assay_20261108/REPORT.md)

## 新补的外折训练家族覆盖

对每个样本，只取对应外折 role=train 的样本，比较旧 UniProt curated_family 字段是否有交集，同一序列组单列计数。未检查匹配样本的实验对象、毒性终点或标签依据。

67 条中，41 条有可用家族注释。其中 21 条在对应训练部分找到至少一条同注释记录，20 条未找到。另 26 条缺家族注释。62 条共同漏判中分别为 18、19、25 条。未找到同注释只表示现有注释和训练子集中没有匹配，不能推出真实家族缺失。不同家族的注释颗粒度不一致，结果也不能说明同终点数据已经覆盖。

| 已有直接损伤证据的共同漏判 | 旧实验对象或证据 | 外折训练同注释样本 / 序列组 |
|---|---|---:|
| EMP-AF、Mastoparan-L、Polybia-MP III | 同一人红细胞实验中均有强溶血，原实验分子为酰胺化形式 | 各 3 / 3 |
| Gs2 | 原文有直接溶血及鱼毒性 | 1 / 1 |
| Pp3 | 原文有溶血证据，末端配对详细读数待核 | 0 / 0 |
| Nc2a | HEK293 细胞实验，红细胞终点另记 | 0 / 0 |
| H1 | 文献摘要有损伤证据，末端及数值待核 | 0 / 0 |
| H2 | 文献摘要有损伤证据，末端及数值待核 | 家族注释未知 |

这几项各有侧重。同注释 Mastoparan 仍共同漏判，值得核对训练邻居的实验终点、分子形式和模型分数。Pp3、Nc2a 暂无同注释训练记录，适合继续核原始来源和同终点覆盖。Gs2 与 Gs1 旧对照已发现六种子排序反向，可继续核该折的同家族训练记录及分子形式。H1/H2 保留定量和化学形式待核状态。

家族覆盖只是线索。原始训练数据缺逐条标签到实验的完整谱系，不能按本表改标签或断定模型错因。下一步可针对以上样本导出对应外折训练同家族邻居，核验家族身份、标签和实验终点，并结合既有同实验对照挑选可独立验证的样本。
