# 六种子一维薄弱点分型

以原嵌套五折的六个一维种子为基线。从六路原始预测取均值，每个外折只用其内部 calibration 角色拟合单调 Platt 校准，再评价该折 test 角色（训练集留出部分）。基准分析仅使用一维概率、原标签和种子间分歧。Test1/2、三维和融合预测都不参加分型。

- `p_true` 为赋给原标签的概率，`BCE = -log(p_true)`，自然对数。`p_true <= 0.10` 为强反向判断，`0.10 < p_true < 0.40` 为较弱反向判断，`0.40 <= p_true <= 0.60` 为近中性，`0.60 < p_true < 0.90` 为较强支持，`p_true >= 0.90` 为高支持参考。0.5 为概率中性点，未设定部署阈值。
- 六路原始概率样本标准差 `>= 0.15` 单独标记为分歧大，与上述类别重叠。种子分数本身不当作逐种子校准概率。种子同时位于该折单调校准曲线的中性点同一侧，可辅助判断意见方向是否一致。
- 阈值仅为描述分层，不用于挑模型或训练权重。保留所有连续值，另用 `p_true <= 0.05 / 0.20` 和距 0.5 不超过 `0.05 / 0.15` 查看结论是否依赖切分。
- 按标签和 Cys 数（0、1–6、≥7）报告样本和序列组数。结构与证据字段只在分型后关联。用同外折、同标签、相同 Cys 数、长度相差不超过 3、不同序列组且种子分歧小的高支持样本作比较。为每条难例取长度最近的参考池，按特征中位数比较。保留匹配覆盖率及跨折方向，允许不同难例共享参考样本，因此只报告描述结果。
- 保留可验证的公开来源标记，包括片段提示、来源标签冲突、家族注释和原标签证据状态。注释覆盖不均，标记不等于错标，缺标记不等于标签已证实。结构为预测构象，结构特征的关联不证明可被三维修复。
- 报告仅用于探索。若用于后续加权，须用当前外折内部且留出对应训练样本的预测重建难度。不能直接把跨外折汇总的分析表用作权重表。
