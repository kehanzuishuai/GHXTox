# 人红细胞配对补充与留出检查

上一轮的原文定量主表保留 **6 篇研究、10 条序列、23 个同剂量配对**。本轮从两篇原文图中补入 **2 条序列、19 个估读配对**，另为羊源肽家族补核 **2 条序列**的人红细胞低反应限值。三个层级分别保留，方便对图读数精度和低信号对照做敏感性分析。下表比较的是游离酸和酰胺两个 C 端形式。红细胞均来自人。

Gomesin 补上了一个来自不同家族、多个浓度方向一致的下降案例，也扩展到含 Cys 的肽。它只能为该实验提供证据，浓度序列不能作为独立复现。正向对照仍可用 Piscidin 3，低差异对照可用 Piscidin 1、AurH1 或 ChBac，但低反应或未达显著不构成等效证明。

2026 年的 Termini 预印本是后续值得追的独立来源。作者在同一人红细胞实验中测了 60 条骨架的 120 个分子形式，报告三次生物重复。部分分子同时改变两端，正文主要给 HC50 拟合值，部分超出实测剂量范围。已查作者的代码及数据入口，本轮未取得能逐样本核对的固定剂量原始读数和对应表，未纳入主表。若取得原始读数，应先恢复每条骨架的单端对比，再按来源留出。 [预印本](https://doi.org/10.64898/2026.04.09.717597) · [作者数据入口](https://data.mendeley.com/datasets/5bknbrhyv5/1)

原文定量主表的 C 端子集只有 **4 篇研究、7 条序列、17 个剂量点**。同一序列两种末端形式在 FASTA 加相同实验条件的模型里必然同分，配对差值为零。对这 7 条序列先在序列内平均绝对差值、再对序列等权平均，零差值基线的误差为 **15.31 个百分点**。这是本表上的诊断值，不能用作泛化指标。增加图估读后也缺跨研究复现的下降样本，暂不拟合模型。

数据补齐后，绝对溶血率和配对差值分别评估。实验条件在各模型间保持一致，按论文、肽家族和相近骨架成组留出。先看 FASTA 加末端状态能降低多少配对差值误差，再在有两种真实分子形式对应结构证据的相同子集上加入 3D，检查是否能继续减少误差。若同一 FASTA 的两种形式使用同一份结构，结构输入无法直接区分两种形式。
