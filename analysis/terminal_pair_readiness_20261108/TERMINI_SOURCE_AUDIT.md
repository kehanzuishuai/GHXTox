# Termini 人红细胞溶血数据核查

已核对 bioRxiv v1 的原始补充文件和作者在 Mendeley Data 发布的 v1 压缩包。**本轮核对了部分肽编号与末端形式，未找到逐剂量溶血百分比，定量主表仍为 6 篇研究、10 条序列、23 个同剂量配对。**

- **bioRxiv 补充文件。** 图 S8 给出肽编号及拟合的 HC50、CC50。文件中未见逐浓度读数、各浓度重复误差或完整的编号与末端形式对应表。正文引用的 Table S9 也不在已下载的补充文件内。 [补充材料](https://www.biorxiv.org/content/10.64898/2026.04.09.717597v1.supplementary-material)
- **作者数据压缩包。** 76 个文件包括抗菌活性建模数据、公共数据库肽序列和二分类毒性训练／测试数据。Data S1.fasta 有 32,095 条记录。抽查两条在正文明确关联编号的实验序列，两条都未出现在该 FASTA 中。压缩包未找到 120 个合成分子的编号映射或逐剂量溶血读数。 [作者数据](https://data.mendeley.com/datasets/5bknbrhyv5/1)
- **实验条件。** 人红细胞来自一位 A− 供者，PBS pH 7.4、室温 4 小时，图 S8 报告三个独立重复。方法写的是与红细胞等体积混合前的肽液浓度范围 0.78–100 µM，图 S8 则用 128 µM 作为显示阈值，最终孔浓度需按实验表核对。 [论文](https://doi.org/10.64898/2026.04.09.717597)

| 论文案例 | 核对结果 |
| --- | --- |
| RRFIKRGKTAIRRRPRAIIIRII | 正文明确映射 24780、24782、24781、24783 四种末端状态，可构造四个只改变单端的比较。图 S8 的四个 HC50 拟合值均超过 2,000 µM，远超实验报告范围。 |
| PWKLWKKVIKLVKKWLRL | 正文明确映射 10152 和 10155。两端同时改变，两个 HC50 拟合值也低于方法所列剂量范围，即使考虑等体积稀释亦然。 |
| KKWKKFFKAAKKFAKKIG | 正文描述游离酸与酰胺形式，用 HC50、CC50 两项在图 S8 交叉定位 8032 与 8034。两组 HC50 均远超实验范围。 |
| 19460、19462 | 图中 HC50 分别为 29.5 和 36.8 µM，落在名义实验范围内。已查材料不足以确认两者序列和末端状态。 |

Termini 可作为论文讨论末端化学的相关工作。若取得原始实验表，接入需要肽编号、裸序列与两个末端状态的映射、最终孔浓度、每次重复的溶血率或原始吸光度及阴阳性对照，以及供者和批次标识。只有同供者、同批次、同剂量且只改变一个末端的记录才能进入固定剂量主表。
